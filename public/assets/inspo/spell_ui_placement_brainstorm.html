Spell UI × Portfolio — placement map
01 · special text
Matrix-style char scramble reveal
_!X$0-+*# → final text, letter by letter
Best placements
heroName reveal on load — "Taeyang Han" decoding from noise on first paint. High impact, immediate attention
navNav links scramble-in on page load or scroll-into-view
statsStat values (5, 30+, 7) scramble to their final numbers — feels earned
Port: pure vanilla JS, no deps. Replace framer inView with IntersectionObserver. The monospace font switching is the only CSS delta.
02 · highlighted text
Ink-sweep block highlight, text stays white
Filled rectangle wipes in, mix-blend-difference reveals text
Best placements
bioWrap "Chem Eng × Intl Business" in the hero bio — highlight the dual major on scroll-trigger
heroWrap "Samsung Scholar" or "PALS President" in the roles line for pull-quote energy
sectionSection headlines — highlight one word in "Projects" / "Certificates" titles as they scroll in
Port: CSS-only via clip-path + transform on a pseudo-element. Motion library not needed — keyframe animation replaces Framer spring. Use your existing magenta as the fill color.
03 · signature
SVG path-draw handwriting animation
opentype.js → per-glyph SVG strokes drawn in real-time
Best placements
heroReplace the plain "Taeyang Han" name with the animated signature — draws in after page load. Premium, personal
footerFooter sign-off — small signature draws when user reaches bottom. Memorable exit moment
Hard dep: opentype.js + LastoriaBoldRegular.otf font file (must host locally in /assets/fonts/). Also requires GSAP or vanilla SVG animation to replace Framer motion's pathLength. Non-trivial port — do last.
04 · gradient wave text
Apple-style animated color wave sweeping through text
rAF loop updating --gi CSS var → radial/linear gradient on background-clip: text
Best placements
heroThe hero tagline / bio sentence — specifically the "unpredictability" word currently using gradient-clip. Upgrade it to an animated wave using your magenta/cyan palette
sectionSection micro-labels ("ABOUT ME", "PROJECTS") — subtle wave on idle adds life without noise
footerFooter name / tagline — slow wave, almost imperceptible. Elegant
Port: easiest of the 5. Zero deps — pure CSS custom property + rAF. Drop the React wrapper, keep the gradient math and tick function. Override defaultColors with your brand palette: magenta → cyan → lime.
05 · animated checkbox
Spring-animated check + strikethrough — interactive list items
SVG pathLength spring → strikethrough div width spring on click
Best placements
projectsProject card "features" or "stack" list — each item is an animated checkbox. Shows completion/ownership without boring bullet points
skillsSkills / tools section — checkboxes for "proficient in", letting visitor click to mark relevance. Adds interactivity with zero backend
hero"What I'm building" sidebar — LifeOS, CNN classifier, scholarship app — animated list with checkboxes feels like a live OS dashboard. Matches LifeOS brand
aboutValues / principles — "Systems over tactics ✓", "Builder not consumer ✓" — pre-checked, draws in on scroll. Personality without being try-hard
Port: simplest. Replace framer motion spring with CSS transition on width + SVG strokeDashoffset animation. 30–40 lines vanilla JS. Checkbox state is purely presentational — no form/backend needed.
Port priority order (easiest → hardest):
1. Gradient Wave Text (pure rAF, zero deps) → 2. Animated Checkbox (CSS transition only) → 3. Highlighted Text (clip-path keyframe) → 4. Special Text (vanilla JS state machine, direct port) → 5. Signature (opentype.js dep, hardest)
